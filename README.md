# cine-track

Projeto da matéria de Sistemas Web do curso de Engenharia de Software - UEM

- Uso de HTML, CSS e JS.
- O CineTrack é um catálogo de filmes, com cadastro, listagem, busca e
filtros.
- Interface com busca por título, filtros de status, lista de filmes
e formulário de cadastro.
- Inclusão, edição e remoção (CRUD).
- Evolui em duas partes: frontend interativo e aplicação full
stack.
